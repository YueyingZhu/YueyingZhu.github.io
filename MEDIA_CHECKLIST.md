# Media checklist for the final academic homepage

Please provide only material that is public or approved for external use. Do not upload confidential Ant Group, customer, production, or internal conference assets.

## Highest priority

1. A natural headshot, ideally 1600 px or wider, with a simple background. Optional for the current typography-led designs.
2. The accepted ICARCV paper PDF or final title page, plus one strong figure/teaser that can be publicly shown.
3. One UMI system overview photo showing the robot, cameras/controllers, and collection setup.
4. A 10–20 second UMI demo clip, preferably landscape 16:9, showing synchronized data collection rather than only the UI.
5. One ego-SLAM input/output clip: egocentric stereo footage with trajectory or reconstruction overlay.
6. One shareable screenshot of the UMI monitoring interface or synchronized camera streams.

## Add when available

7. Conditional-grasping setup photo and a short clip containing task condition, candidate grasps, and final real-robot execution.
8. AAAI-27 teaser image or short comparison GIF/video if the submission policy and coauthors allow public posting.
9. Full author order for the AAAI-27 submission, so the temporary “Yueying Zhu (second author), et al.” entry can become a standard citation.
10. Public links for paper PDFs, project pages, code, videos, Google Scholar, and LinkedIn if desired.

## Useful delivery format

- Images: original JPG/PNG/WebP, not screenshots pasted into a document.
- Video: MP4/H.264, 1080p when possible, with a silent version or captions.
- Each file: include a one-sentence caption, public/private status, and the project it belongs to.
